# 光伏电站运行维护管理平台

面向电站台账、组串阵列、逆变器、汇流箱、跟踪支架、组件清洗、告警处置与发电结算的一体化光伏电站运行维护工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化 / 消防器材共享规则
│   ├── scripts/              构建前自检（selfcheck.mjs 运行 fire-selfcheck.ts）
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

`npm run build` 会先跑**消防器材台账构建前自检**（`npm run selfcheck` 可单独执行），自检不过
直接中止构建，不允许上线。自检把 `src/data/seed.ts` 里的示例数据喂给数据层规则：

- 压力越限（欠压 `<1.00MPa`、超压 `>1.40MPa`）与检查周期超期各报各的；
- 校验示例状态与规则推导一致、存量回填幂等、压力边界判定正确；
- 校验消防页「压力不足器材」数与巡视检查页「待复核清单」条数一致；
- 校验样例批次重复导入不会新增重复器材（按器材编号幂等）。

自检支持指定基准日：`node scripts/selfcheck.mjs 2026-10-04`（默认取 UTC 当天，UTC 口径保证
开发机与容器结论一致）。容器镜像（`frontend/Dockerfile`）构建时也会跑同一道自检。

### 消防器材规则口径（共享实现）

压力判定与检查周期判定**只**在 `frontend/src/data/fire-rules.ts` 一份实现，消防页面、巡视
待复核清单、本地存储归一化与构建自检全部复用：

| 规则 | 口径 |
| --- | --- |
| 压力合格区间 | `[1.00, 1.40] MPa`，低于下限判「欠压」，高于上限判「超压」，两者都计入「压力不足器材」 |
| 检查周期 | 显式天数（`30天`/`45日`）或 `月度=30`、`季度=90`、`年度=365`、`周=7`；应检日 = 检查日期 + 周期天数，基准日晚于应检日判「超期未检」 |
| 终态豁免 | 「已更换」器材不再判定压力与周期 |
| 存量回填 | 压力读数不是合法数值时按检查日期确定性回填（原登记为压力不足的回填到下限以下，保持原判定）；周期不可解析回填 `30天` |
| 日期 | 一律按 UTC 解析与比较，不依赖运行环境时区 |

消防页面新增「导入样例」按钮，用于演示幂等导入；巡视检查页面底部展示「待复核清单：消防器材
压力越限」，数据与消防台账同源。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 消防器材的压力与周期判定是跨页面、台账、构建自检的共享规则，只允许改
  `frontend/src/data/fire-rules.ts`，任何来源的消防记录读入数据层时都会先过这份规则。
- 想回到初始数据：清掉浏览器里 `pv-plant-ops:entries` 这一项，或调用 `resetModule(模块)`。
